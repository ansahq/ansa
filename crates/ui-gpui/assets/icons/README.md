# Icon artwork

The interface glyphs are exported from the [Rust/UI icon registry](https://github.com/rust-ui/icons/blob/177b78d53a0fcf5e707effe18d788514b8ea9f5f/src/common/icon_registry_elements.rs) at revision `177b78d53a0fcf5e707effe18d788514b8ea9f5f`. GPUI renders the SVGs directly. See [Rust/UI's MIT license](RUST-UI-LICENSE) and the [Lucide notices](LICENSE).

The Ansa logo is local artwork. Application icons are loaded from the system at runtime.
